# ኢ-Sport Ethiopia - Tournament & Arena

**Created by Gaming Bridge Team 20 for a gaming competition in Ethiopia.**

This project is a static website and is ready to publish.

## Local Preview

From this folder, run:

```bash
py -m http.server 8000
```

Then open:

http://localhost:8000/

## Publish to the Internet

### Option 1: GitHub Pages

1. Open your GitHub repository.
2. Go to Settings → Pages.
3. Select the `main` branch.
4. Select the root folder `/`.
5. Click Save.
6. GitHub will provide your public website URL.

### Option 2: Netlify

1. Visit https://www.netlify.com
2. Import your GitHub repository.
3. Deploy your website.

### Option 3: Vercel

1. Visit https://vercel.com
2. Import your GitHub repository.
3. Keep the default static-site settings.
4. Deploy.

This website uses CDN-based CSS and fonts, so it can run as a static website without a build step.
